# Resumaker

Resumaker is a simple React project built around a practical problem I repeatedly encountered while applying for software roles: a résumé can be technically good but still perform poorly when it is formatted badly. LaTeX is very good for making professional a résumé but I wanted to make the process of tailoring a résumé easier and avoid re-writing LaTeX.

Resumaker is just a web-app with controlled inputs and a big div styled like a professional résumé. You just type in the details and it will fill them into the professional résumé template. You can add different blocks for education, experience, tooling and projects, with dates, links and icons. I made a few résumés using it and ran some online ATS tests on them, all scored above 90. I plan on adding a few more template styles and some storage capabilities to it.

It is a good example of a small product with a real user problem: structured input, text processing, good ATS, and a useful professional template, all have to work together. It is a very simple project and yet me and friends use it to write résumés all the time. There is no login, no storage, you just go and start typing the details.
